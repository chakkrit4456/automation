# ขึ้นใช้งานจริง (เซิร์ฟเวอร์ Debian + Docker)

ทำตามลำดับนี้ครั้งเดียว ใช้เวลาฝั่งเซิร์ฟเวอร์ประมาณ 30 นาที ส่วนที่นานคือรออนุมัติจากแพลตฟอร์ม (ข้อ 6)

## ภาพรวม

```text
อินเทอร์เน็ต ──HTTPS──> Nginx (โฮสต์) ──> app :3000  (API + แดชบอร์ด + FFmpeg + edge-tts)
                                     └──> n8n :5678  (ตั้งเวลารันทุกวัน)
                                              │
                                  postgres (เครือข่ายภายใน Docker เท่านั้น)
```

- `app` เปิดพอร์ตแค่ `127.0.0.1` ภายนอกเข้าได้ผ่าน Nginx เท่านั้น
- PostgreSQL ไม่เปิดพอร์ตออกนอก Docker
- วิดีโอเก็บใน volume `media_data`

## 1. เตรียมเซิร์ฟเวอร์

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl git nginx certbot python3-certbot-nginx
# ติดตั้ง Docker Engine + Compose plugin ตามเอกสารทางการ: https://docs.docker.com/engine/install/debian/
```

ชี้โดเมน 2 ชื่อมาที่ IP เซิร์ฟเวอร์ เช่น `app.example.com` และ `n8n.example.com`

## 2. วางโปรเจกต์และสร้าง .env

```bash
sudo mkdir -p /opt/ai-social-automation && sudo chown $USER /opt/ai-social-automation
cd /opt/ai-social-automation
# คัดลอกไฟล์โปรเจกต์มาที่นี่ (git clone หรือ scp)
sudo apt-get install -y nodejs   # ใช้แค่รันสคริปต์สร้าง .env หรือจะคัดลอก .env.example แล้วแก้มือก็ได้
node scripts/make-env.js
nano .env
```

แก้ใน `.env`

| ตัวแปร | ค่า |
| --- | --- |
| `PUBLIC_URL` | `https://app.example.com` |
| `ADMIN_EMAIL` | อีเมลที่ใช้เข้าแดชบอร์ด |
| `ANTHROPIC_API_KEY` | คีย์จาก console.anthropic.com |
| `N8N_HOST` / `N8N_PROTOCOL` / `N8N_EDITOR_BASE_URL` | `n8n.example.com` / `https` / `https://n8n.example.com/` |
| `N8N_SECURE_COOKIE` | `true` |
| `PUBLISHER_MODE` | ปล่อย `mock` ไว้ก่อน จนกว่าจะเชื่อมบัญชีและทดสอบเสร็จ |

รหัสลับทุกตัวถูกสุ่มไว้แล้ว ห้ามใช้ `@ : / #` ในรหัส `POSTGRES_PASSWORD` เพราะรหัสนี้อยู่ใน URL ฐานข้อมูล

## 3. สตาร์ท

```bash
docker compose up -d --build
docker compose ps
curl -s http://127.0.0.1:3000/api/ready
```

ต้องได้ `{"status":"ready","database":"ok"}` ตารางฐานข้อมูลถูกสร้างอัตโนมัติ

## 4. Nginx + HTTPS

```bash
sudo cp deploy/nginx/ai-social.conf /etc/nginx/sites-available/ai-social
sudo nano /etc/nginx/sites-available/ai-social   # เปลี่ยน example.com เป็นโดเมนจริง
sudo ln -s /etc/nginx/sites-available/ai-social /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d app.example.com -d n8n.example.com
```

เปิด `https://app.example.com` แล้วเข้าสู่ระบบด้วย `ADMIN_EMAIL` / `ADMIN_PASSWORD` จาก `.env`

## 5. n8n (ตั้งเวลาโพสต์ทุกวัน)

```bash
docker compose exec n8n n8n import:workflow --input=/workflows/daily-scheduler.json
docker compose restart n8n
```

เปิด `https://n8n.example.com` สร้างบัญชีเจ้าของ (ครั้งแรกเท่านั้น) เปิดเวิร์กโฟลว์ "Daily scheduler" แล้วกด Active เวิร์กโฟลว์เรียก `POST /api/automation/run-now` ทุกวันตอน 09:00 เวลาไทย

แอปมีตัวตั้งเวลาในตัวด้วย ซึ่งตรวจทุกนาทีเมื่อเปิด "ระบบอัตโนมัติ" ในแดชบอร์ด การโพสต์ใช้ idempotency จึงไม่โพสต์ซ้ำแม้ทั้งสองทางทำงานพร้อมกัน ใช้ n8n เมื่ออยากเพิ่มขั้นตอนอื่น เช่น แจ้งเตือน LINE หรือ Slack

## 6. เชื่อมบัญชีโซเชียล

ทำตาม [13-oauth-setup.md](13-oauth-setup.md) ทีละแพลตฟอร์ม แล้วใส่ client id/secret ใน `.env` และรัน `docker compose up -d app`

| แพลตฟอร์ม | โพสต์ได้ทันทีหลังเชื่อม | ต้องรออนุมัติเมื่อ |
| --- | --- | --- |
| YouTube | ได้ แต่คลิปจะถูกล็อกเป็น private จนกว่าโปรเจกต์ผ่าน API audit | อยากให้คลิปเป็น public |
| Facebook Reels | ได้ ถ้าบัญชีมีบทบาทในแอป Meta (admin/developer/tester) | โพสต์ให้ Page ของคนอื่น (ต้องผ่าน App Review) |
| Instagram Reels | ได้ เงื่อนไขเดียวกับ Facebook และต้องเป็นบัญชี Professional ที่ผูกกับ Page | เหมือน Facebook |
| TikTok | ได้ แต่เป็น `SELF_ONLY` (เห็นคนเดียว) | อยากโพสต์สาธารณะ (ต้องผ่าน audit ของ TikTok) |

ในแดชบอร์ด ไปที่ "บัญชีโซเชียล" กด "เชื่อมต่อ" ล็อกอินที่หน้าแพลตฟอร์ม แล้วกด "ทดสอบ"

### หลายบัญชีต่อแพลตฟอร์ม

- กด "+ เพิ่มบัญชี" ได้หลายครั้ง Facebook/Instagram ติ๊กเลือกหลาย Page ได้ในครั้งเดียว ส่วน YouTube/TikTok ต้องล็อกอินทีละบัญชี (ออกจากระบบบัญชีเดิมในเว็บนั้นก่อน หรือใช้หน้าต่างไม่ระบุตัวตน)
- บัญชีแรกของแต่ละแพลตฟอร์มเป็น "ค่าเริ่มต้น" เปลี่ยนได้ด้วยปุ่ม "ตั้งเป็นค่าเริ่มต้น"
- เลือกบัญชีปลายทางได้ในหน้าต่างตั้งเวลา หน้า AI สร้างคอนเทนต์ และหน้าระบบอัตโนมัติ ถ้าแพลตฟอร์มไหนไม่ได้ติ๊กบัญชี ระบบจะใช้บัญชีค่าเริ่มต้น

## 7. เปิดโพสต์จริง

1. ใน `.env` ตั้ง `PUBLISHER_MODE=live` แล้วรัน `docker compose up -d app`
2. หน้า "บัญชีโซเชียล" กด "ทดสอบ" ทุกบัญชี ต้องขึ้นว่าเชื่อมต่อได้
3. สร้างคอนเทนต์ 1 ชิ้น ไปหน้าสตูดิโอ กด "สร้างวิดีโอ" รอจนเล่นได้
4. กดเผยแพร่ทีละแพลตฟอร์มก่อน ดูผลในหน้า "การเผยแพร่" และ "บันทึกระบบ"
5. เมื่อผ่าน ค่อยเปิดระบบอัตโนมัติ

## อัปเดตเวอร์ชัน (ฐานข้อมูลปรับให้อัตโนมัติ)

```bash
docker compose exec -T postgres pg_dump -U ai_social -d ai_social --format=custom > backups/before-upgrade.dump   # สำรองก่อนทุกครั้ง
docker compose up -d --build app
docker compose logs app | grep -i migration
```

ตอนสตาร์ท แอปจะรันไฟล์ใน `database/migrations/` ที่ยังไม่เคยรัน ถ้าไฟล์ไหนล้มเหลว จะย้อนกลับไฟล์นั้นและแอปไม่สตาร์ท ฐานข้อมูลจึงไม่ค้างครึ่งทาง รายละเอียดอยู่ใน [05-database.md](05-database.md)

## ดูแลระบบ

```bash
docker compose logs -f app                      # ดู log
docker compose exec -T postgres pg_dump -U ai_social ai_social > backup-$(date +%F).sql   # สำรอง
docker compose up -d --build app                # อัปเดตหลังแก้โค้ด
```

ข้อจำกัดบนเครื่อง 2 GB / 1 vCPU: เรนเดอร์คลิป 45 วินาทีใช้ประมาณ 1–2 นาที และเรนเดอร์ได้ทีละคลิป YouTube API มีโควตาประมาณ 6 คลิปต่อวันต่อโปรเจกต์
