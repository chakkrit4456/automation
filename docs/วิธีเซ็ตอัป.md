# วิธีเซ็ตอัปโปรเจกต์ให้พร้อมใช้งาน

ทำครั้งเดียวบนเครื่อง Windows หลังจากนั้นใช้ [วิธีรัน.md](วิธีรัน.md) ได้เลย

พร้อมใช้งานในขั้นนี้หมายถึง แดชบอร์ดเปิดได้ เข้าสู่ระบบได้ มีคอนเทนต์ตัวอย่าง และกดสร้างคอนเทนต์หรือตั้งเวลาได้โดยยังไม่ต้องมีคีย์ Claude หรือแอปโซเชียล

## 1. ติดตั้งโปรแกรม

ติดตั้งอย่างใดอย่างหนึ่ง แล้วเปิด PowerShell ใหม่

- [Node.js 22](https://nodejs.org/) หรือใหม่กว่า เลือกตัวติดตั้งแบบ LTS ที่เป็นเวอร์ชัน 22 ขึ้นไป
- ตรวจด้วยคำสั่งนี้ ต้องขึ้นเวอร์ชัน ไม่ใช่ข้อความว่าไม่พบคำสั่ง

```powershell
node -v
npm -v
```

ติดตั้งเพิ่มเมื่อต้องการใช้ส่วนนั้น

| โปรแกรม | ใช้เมื่อ | ติดตั้ง |
| --- | --- | --- |
| FFmpeg | เรนเดอร์วิดีโอ MP4 จริง (พื้นหลัง + ข้อความ hook + ซับไทย) ถ้าไม่มี หน้าสตูดิโอจะแสดงข้อมูลจำลอง | `winget install Gyan.FFmpeg` |
| Python + edge-tts | เสียงพากย์ภาษาไทยฟรี ถ้าไม่มี วิดีโอจะไม่มีเสียงพากย์แต่ยังมีซับ | `pip install edge-tts` |
| Docker Desktop | เก็บข้อมูลใน PostgreSQL หรือรันทั้งชุดแบบเดียวกับเซิร์ฟเวอร์ | [docker.com](https://www.docker.com/products/docker-desktop/) |

ถ้ารันด้วย Docker (ดู [14-ขึ้นใช้งานจริง.md](14-ขึ้นใช้งานจริง.md)) ไม่ต้องติดตั้ง FFmpeg กับ edge-tts บนเครื่อง เพราะมีอยู่ในอิมเมจแล้ว

## 2. ติดตั้งแพ็กเกจของโปรเจกต์

```powershell
cd d:\Project-automation-video-ai\backend
npm install
cd d:\Project-automation-video-ai\frontend
npm install
```

## 3. ไฟล์สภาพแวดล้อม

สำหรับลองบนเครื่องนี้ ข้ามขั้นนี้ได้ ระบบจะใช้ค่าพัฒนาเอง

- อีเมล `admin@localhost`
- รหัสผ่าน `changeme`
- ไม่ต่อฐานข้อมูล ข้อมูลอยู่ชั่วคราวในหน่วยความจำ
- มีคอนเทนต์ตัวอย่างให้ดู
- โหมดเผยแพร่เป็น `mock` ไม่ยิง API จริงของ TikTok, Instagram, Facebook หรือ YouTube

เมื่อจะใส่คีย์จริงหรือจะขึ้นเซิร์ฟเวอร์ ให้สร้าง `.env` ด้วยสคริปต์ มันสุ่มรหัสลับทุกตัวให้เอง

```powershell
cd d:\Project-automation-video-ai
node scripts/make-env.js --local
```

- `--local` ใช้บนเครื่องนี้ (โหมดพัฒนา, `PUBLIC_URL=http://localhost:5173`, ฟอนต์ซับ Leelawadee UI)
- ไม่ใส่ `--local` ใช้บนเซิร์ฟเวอร์ (โหมด production)
- รหัสแอดมินอยู่ในบรรทัด `ADMIN_PASSWORD` ของ `.env`
- `npm run dev` อ่าน `.env` ให้อัตโนมัติ

อย่าคอมมิตไฟล์ `.env`

## 4. ฐานข้อมูล (ทำเมื่ออยากให้ข้อมูลคงอยู่)

ค่าเริ่มต้นของ Docker ไม่เปิดพอร์ต 5432 ออกอินเทอร์เน็ต ฐานข้อมูลอยู่บนเครือข่ายภายในของ Docker

ถ้าจะให้ API บน Windows ต่อเข้า PostgreSQL ในคอนเทนเนอร์ ต้องเปิดพอร์ตเฉพาะบนเครื่องนี้ชั่วคราว โดยเพิ่มใต้บริการ `postgres` ใน `docker-compose.yml` เฉพาะตอนพัฒนา

```yaml
ports:
  - "127.0.0.1:5432:5432"
```

จากนั้น

```powershell
cd d:\Project-automation-video-ai
docker compose up -d postgres
```

ใน `.env` ตั้งบรรทัดนี้ให้รหัสตรงกับ `POSTGRES_PASSWORD`

```text
DATABASE_URL=postgresql://ai_social:รหัสของคุณ@127.0.0.1:5432/ai_social
SEED_DEMO=true
```

API จะสร้างตารางเองตอนสตาร์ท บนเซิร์ฟเวอร์ Debian อย่าเปิดพอร์ต 5432 แบบนี้ ให้ `DATABASE_URL` ชี้โฮสต์ชื่อ `postgres` ตาม `.env.example`

## 5. รันให้ใช้งานได้

ทำตาม [วิธีรัน.md](วิธีรัน.md)

1. หน้าต่างแรก: `cd d:\Project-automation-video-ai\backend` แล้ว `npm run dev`
2. หน้าต่างที่สอง: `cd d:\Project-automation-video-ai\frontend` แล้ว `npm run dev`
3. เปิด http://localhost:5173
4. เข้าสู่ระบบด้วย `admin@localhost` / `changeme` หรือรหัสที่ตั้งใน `.env`

ถ้าเข้าได้และเห็นแดชบอร์ด โปรเจกต์พร้อมใช้งานในโหมดพัฒนา

## 6. สิ่งที่ยังตั้งทีหลังได้

ระบบทำงานได้ก่อนตั้งค่าเหล่านี้

| สิ่งที่ตั้ง | ตัวแปร | ผลเมื่อตั้งแล้ว |
| --- | --- | --- |
| คีย์ Claude | `ANTHROPIC_API_KEY` จาก console.anthropic.com | ปุ่มสร้างคอนเทนต์เรียก Claude API ปุ่ม "ทดสอบ" ในหน้าตั้งค่าจะเช็กกับ API จริง บัญชี Claude Pro ไม่นับเป็นเครดิต API |
| เรนเดอร์วิดีโอ | ติดตั้ง FFmpeg และ edge-tts แล้วเปิด API ใหม่ | สตูดิโอสร้าง MP4 1080×1920 พร้อมเสียงพากย์ไทยและซับ เล่นและดาวน์โหลดได้ในหน้าสตูดิโอ |
| เสียงพากย์ | `TTS_VOICE`, `TTS_RATE` | `th-TH-PremwadeeNeural` (หญิง) หรือ `th-TH-NiwatNeural` (ชาย) |
| โพสต์จริง | client id/secret ตาม [13-oauth-setup.md](13-oauth-setup.md) แล้วตั้ง `PUBLISHER_MODE=live` | กด "เชื่อมต่อ" ในหน้าบัญชีโซเชียล แล้วระบบอัปโหลดผ่าน API ทางการของ YouTube, Facebook Reels, Instagram Reels และ TikTok |
| n8n | `docker compose up -d n8n` | เรียก `POST /api/automation/run-now` ทุกวันตามเวิร์กโฟลว์ |
| เซิร์ฟเวอร์ | [14-ขึ้นใช้งานจริง.md](14-ขึ้นใช้งานจริง.md) | รันทั้งชุดด้วย Docker Compose + Nginx + HTTPS |

ก่อนขึ้นโปรดักชัน ให้สร้างแดชบอร์ดแล้วให้ API เสิร์ฟไฟล์นั้น

```powershell
cd d:\Project-automation-video-ai\frontend
npm run build
```

ตั้ง `NODE_ENV=production` และ `DATABASE_URL` ให้ชี้ PostgreSQL บนเซิร์ฟเวอร์ ห้ามใช้รหัส `changeme`
