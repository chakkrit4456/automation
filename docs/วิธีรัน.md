# วิธีรัน

รันบน Windows ด้วย PowerShell สองหน้าต่าง หน้าต่างหนึ่งสำหรับ API และอีกหน้าต่างสำหรับแดชบอร์ด

## รหัสแอดมิน

ถ้ามีไฟล์ `.env` (สร้างด้วย `node scripts/make-env.js --local`) ให้ใช้ `ADMIN_EMAIL` และ `ADMIN_PASSWORD` จากไฟล์นั้น

ค่าด้านล่างใช้เฉพาะเมื่อไม่มีไฟล์ `.env`

| ช่อง | ค่า |
| --- | --- |
| อีเมล | `admin@localhost` |
| รหัสผ่าน | `changeme` |

เปิดแดชบอร์ดที่ http://localhost:5173 แล้วใส่สองค่านี้

ถ้ารันด้วย `NODE_ENV=production` รหัส `changeme` ใช้ไม่ได้ ต้องตั้งรหัสใหม่ใน `.env` ก่อน

## สิ่งที่ต้องมี

- Node.js 22 ขึ้นไป
- เปิดโฟลเดอร์โปรเจกต์ `d:\Project-automation-video-ai`

ติดตั้งแพ็กเกจครั้งแรกตาม [วิธีเซ็ตอัป.md](วิธีเซ็ตอัป.md) จากนั้นใช้คำสั่งด้านล่างได้ทุกครั้ง

## 1. เปิด API

```powershell
cd d:\Project-automation-video-ai\backend
npm run dev
```

รอจนเห็นข้อความ `listening on 3000`

- API: http://127.0.0.1:3000
- ตรวจว่าโปรเซสยังทำงาน: http://127.0.0.1:3000/api/health ต้องได้ `{"status":"ok"}`

ถ้าไม่ได้ตั้ง `DATABASE_URL` ข้อมูลอยู่แค่ในหน่วยความจำ พอปิดหรือรีสตาร์ท API ข้อมูลตัวอย่างจะถูกสร้างใหม่ และต้องเข้าสู่ระบบใหม่

## 2. เปิดแดชบอร์ด

เปิด PowerShell อีกหน้าต่าง

```powershell
cd d:\Project-automation-video-ai\frontend
npm run dev
```

รอจนเห็น `Local: http://localhost:5173/`

เปิดเบราว์เซอร์ที่ http://localhost:5173 แล้วเข้าสู่ระบบด้วยรหัสด้านบน

## ปิดโปรแกรม

ที่หน้าต่าง PowerShell ของ API และของแดชบอร์ด กด `Ctrl+C`
