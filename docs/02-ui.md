- generated count
- published count

- today's video preview
- per-platform status
- recent errors
- recent activity

- Today's Videos
- Scheduled
- Published
- Failed
- Connected Accounts

## 5. Calendar

Monthly / weekly calendar.

Each scheduled content card:
- thumbnail
- topic
- time
- platform badges
- status

Support:
- drag/drop reschedule
- open content
- cancel schedule

## 6. Automation

Settings:
- enabled
- timezone
- daily quantity
- publish time
- content generation lead time
- platforms
- retry count
- retry delay
- max concurrent jobs

Default:
- timezone: Asia/Bangkok
- daily quantity: 1
- publish time: 09:00

## 8. Publishing

Show every platform independently.

Example:

```text
Content #102

TikTok       SUCCESS
Instagram    SUCCESS
Facebook     FAILED
YouTube      SUCCESS

Facebook error:
OAuth token expired

[Reconnect] [Retry]
```

## 9. Analytics

Initial metrics:
- videos generated
- videos published
- failed publishes
- publishing success rate
- views if APIs expose them
- likes
- comments
- shares
- engagement rate

Do not invent metrics that a platform API does not provide.
